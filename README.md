# 2D-Game — PC Master: Scrap to Top

Godot 4.7 2D browser game project (vertical slice).

## Run
Open `project.godot` in Godot 4.7.2+ and run the main scene `scenes/boot/boot.tscn`.

## Structure
- `scenes/` — boot, UI, workshop
- `scripts/` — core, gameplay, services
- `resources/balance/` — components and orders JSON

## Notes
- Web export templates are not installed in this environment; export preset to be configured before publishing.
- `/docs` is intentionally ignored by Git.
